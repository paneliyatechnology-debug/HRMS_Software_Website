2. **Never Touch Frontend**: Never edit, create, delete, move, format, or modify any Frontend files or directories.
3. **Never Access Frontend Repo**: Do not access, read, modify, or delete anything inside Keyur's separate Frontend repository (`C:\Keyur-back\HRMS_Software`).
4. **No Frontend Modifications**: Never modify frontend components, UI, API calls, client configuration, or client dependencies.
5. **API Contracts Over Frontend Code**: If a feature or task requires frontend changes, document and explain the required API contract, request payload, or response structure to Keyur instead of modifying frontend code.
6. **Preserve Backend Stability**: Preserve existing backend functionality, database schemas, and dependencies unless a task specifically requires modification.
7. **Path Verification**: Verify every target file path before making changes to ensure it is strictly within the backend repository.
8. **No Destructive Git Operations**: Do not perform git reset, git clean, stash clearing, or mass deletions.
