# Paneliya HRMS — Enterprise Backend API (Nest.js)

Standalone backend service for Paneliya HRMS.

## Running the Backend

### Development Mode
`ash
npm run start:dev
``nServer will run on: http://localhost:4000/api

### Production Build
`ash
npm run build
npm run start:prod
``n
### Swagger OpenAPI Documentation
http://localhost:4000/api/docs

## Connected Frontend
Frontend is located at: `D:\paneliya technology\paneliya HRMS`
Frontend connects via: http://localhost:4000/api and WebSocket on port 4000.
